# Hospital Encounters Analysis Dashboard

An interactive Microsoft Excel dashboard analyzing hospital encounters and patient admission patterns for the year 2025.

## 📊 Project Overview

This project explores hospital encounter data to provide an overview of patient admissions, length of stay, readmissions, occupancy, admission types, departmental activity, and healthcare costs.

The analysis was presented through an interactive Excel dashboard with PivotTables, PivotCharts, slicers, and a timeline.

## 🎯 Objectives

- Analyze the number of hospital encounters by department
- Examine average length of stay across departments
- Analyze admission types
- Track monthly hospital encounters
- Evaluate 30-day readmission rates by department
- Examine hospital occupancy
- Analyze total healthcare costs and cost per encounter
- Provide an interactive dashboard for exploring hospital encounter patterns

## 📈 Dashboard Highlights

The dashboard reports:

- **Total Encounters:** 300
- **Average Length of Stay:** 5.0 days
- **30-Day Readmission Rate:** 10%
- **Average Occupancy Rate:** 71%
- **Total Cost:** ₦637,189
- **Total Cost per Encounter:** ₦2,124
